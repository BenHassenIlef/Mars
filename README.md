# 🔴 Mars Chatbot

> 🤖 An AI-powered conversational assistant that answers all your questions about the Red Planet — from geology and climate to missions and future colonization.

## 📌 Overview

**Mars Chatbot** lets users explore Mars through natural conversation. Ask anything — "How long is a day on Mars?", "What did the Perseverance rover discover?" — and get clear, accurate answers in real time.

## ✨ Features

- 💬 **Natural conversations** — ask questions in plain language
- 🪐 **Rich Mars knowledge** — geology, atmosphere, moons, missions & exploration history
- 🧠 **AI-powered responses** — built on LLMs with prompt engineering
- ⚡ **Real-time answers** — fast, interactive chat experience
- 🌍 **Beginner-friendly** — designed for curious minds, students & space enthusiasts
